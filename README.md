# 汉语熊猫 · ХаньюйТун

面向俄语使用者的中文学习应用。界面使用俄语，设计和结构参照「俄语熊」：白底、黑色按钮、浅蓝卡片、原创线稿，吉祥物为熊猫。

- 网页入口：https://shizhongzhou.github.io/hanyutong/
- 版本：1.5.0

## 功能

底部四个入口：**Сегодня（今日）**、**Учёба（学习）**、**Повторение（复习）**、**Профиль（我的）**。

- 今日：问候、本周打卡、每日目标进度、今日计划（复习 / 新词 / 小测）、查词、单词本、统计、每日一句
- 学习路径：01 声调与拼音 → 02 HSK 词汇 → 03 对话与听力 → 04 阅读与写作
- 单项练习：语法、听力、跟读（录音回放，浏览器支持时做中文语音识别对照）、写作（拼音或汉字输入）、声调训练、词汇计时训练（10 分钟，非正式模拟考试）
- 统一 HSK 课程：以新版 1–9 级 **11,000 条**官方词汇为主线，融合旧课程 4,991 词，保留其中 295 条未重复的词或读音，共 **11,295 张词卡**。阶段为 1 / 2 / 3 / 4 / 5 / 6 / 7–9；补充词明确标注，旧教学释义与学习记录保留。支持按级/累计词表、汉字/拼音/俄语检索、收藏及间隔复习
- 新版题型：**74 个题型分项、75 个原创练习示例**，覆盖听力、阅读、书写、口语以及高级翻译；俄语说明与解析，图题使用原创图标组合，听力用设备中文语音。主观题提供参考和自评，不冒充 AI 批改或正式考试成绩
- 沉浸式背词：日期与学习日历、叠放彩色词卡、点击翻面、拖动切卡、俄语释义回忆输入、可拖动词云与贴纸；支持字体大小、每日新词量和发音设置。词云支持重力碰撞，兼容设备可主动开启手机倾斜控制。仅切卡不计正确答案
- 间隔复习（1/2/4/7/15/30/60/120 天），答错的词自动进入「我的单词本」
- 中俄翻译：输入文字中俄互译，支持自动识别原文语言、交换方向、复制和设备朗读
- 拍照翻译：相机拍照或选择相册图片，预览后主动上传识别；识别文字可以编辑后再翻译。照片先在设备压缩并移除原始元数据，不保存照片和翻译历史
- AI 对话与讲解：按 HSK 1–9 选择目标难度，中文、拼音、俄语翻译、详细讲解与纠错分区显示；提示模型优先使用已学词，每次最多显示两条新词建议，可主动加入单词本。对话通过 DeepSeek 完成，不持久保存聊天历史
- AI 中文语音：配置普通按量付费 Qwen API 后，可主动录制最多 30 秒语音、点击识别并修改文字后再发送，也可点击中文句子播放；不会自动上传录音或自动朗读
- AI 作业练习：27 个原创任务，覆盖 1–9 难度的写作、口述内容和语法；依据服务端固定题目与评分规则给教学反馈、修改稿和参考例文。当前不设置会员或付款门槛，保留云端用量保护
- 单音节声调练习：录制一个「ma」并在设备本地比较实际基频曲线与示意曲线；不确定时不判断，不评音素、语流、流利度，也不换算 HSK 成绩
- 本机学习画像：已学词、语法/用词提示类别及次数、较明确的单音节声调形状偏差；不保存聊天原句。用户可单独清空这些提示，不删除单词本或学习进度
- 回答纠错反馈：预览将提交的问题与回答，选择原因并单独同意后才写入私有云端反馈区；不自动记录完整对话
- 单词详情页：笔顺动画、例句、组成该词的单字；点任何词都能打开
- 汉字书写：按笔顺在屏幕上描写，可显示轮廓和演示（Hanzi Writer）
- 趣味背词：「Найди пару」配对游戏、按词频大小排列的词云
- 「Мои учебники」教材书架：一次导入整个文件夹（如《成功之路》Road to Success 全套），每个子文件夹成为一册书；PDF 阅读并记页码，音频播放记进度、可变速、单句重复、自动下一轨。文件保存在本机 IndexedDB，不上传服务器
- 查词：保留 HSK 1–6 全部 4991 词，新增大БКРС 的 **1,800,215 条汉俄条目**（其中 **25,070 个单字**、**33,260 条带独立俄语例句的条目**）。包含词、术语、名称及短语，不宣称穷尽中文全部词汇；支持汉字或前缀、拼音、俄语关键词搜索
- 「Спросить панду」浮动按钮：保留本地汉俄词典查询，并提供明显的 AI 对话入口
- 单字字典：Unicode Unihan 17.0.0 的 **102,998 个汉字资料记录**，显示可用的部首、笔画、读音和繁简关联；无俄语释义的字明确提示，不显示英文兜底
- 长俄语释义完整显示，保留词典例句；6 个原创俄语用法说明和情景练习，可先作答再看示范
- 新词可收藏并加入间隔复习；已保存的扩展词条随进度码备份
- 计划、设置、进度码备份与恢复；内置练习首次打开后离线可用（云教材只在线查看），大词库按需下载并缓存已访问分片，浏览器可能因空间不足清理缓存

词卡和现有练习的发音使用设备自带的中文语音（zh-CN）；设备没有中文语音时会提示安装。AI 对话页的语音由 Qwen 提供，是否可用由云端独立开关和凭据决定。未开通 Qwen 语音不影响文字对话。

- 旧 HSK 2.0 六份词表的俄语释义、对话、阅读和语法讲解由本应用编写。旧词表俄语为简短释义，**未经母语者人工校对**，发现不准确的地方欢迎修正 `web/data/hsk*.json`。
- 旧词库多音字按常用读音选取，少数词的拼音可能需要人工核对；新版 HSK 3.0 读音按官方大纲保留。

## HSK 3.0 新版词表与题型

词表依据中外语言交流合作中心 **2025 年 11 月《中文水平考试 HSK 考试大纲》**，来源、原文件 SHA-256、提取页码及俄语词典版本记录于 `hsk3-sources.json` 和 `web/data/hsk3/manifest.json`。这不是 2021 年《国际中文教育中文水平等级标准》的 11,092 词表。各级累计词数为 **300 / 500 / 1,000 / 2,000 / 3,600 / 5,400 / 11,000**，各级新增分别为 300 / 200 / 500 / 1,000 / 1,600 / 1,800 / 5,600。7–9 级官方共用一个词表和一个高级考试，不能人为拆成三个独立词表。

11,000 个官方序号全部保留，包括 82 条带数字标记的独立义项。每条记录包含唯一 ID、原始词头、读音、词性、附加词性等级及 PDF 页码。俄语并非官方大纲自带翻译：4,670 条在词头和带调拼音一致时复用既有教学释义，6,330 条按精确词头取大БКРС 完整释义，无英语兜底。编号义项和多音词保留独立进度，释义说明为完整词头范围；不声称已完成每个官方义项的人工俄译。官方第 3183 条“为2（介）”拼音为 `wéi`，按原文照录，不在无官方勘误的情况下改写。

完整词典条目可能先列其他读音或词性。词汇选择题因此只从无编号、无同形歧义且具有简短教学释义的条目取题，完整 11,000 条都可阅读和使用词卡。词典释义未经全量俄语母语者校对；后续校订应保留官方词表与译文来源的区别。

题型按 CTI 发布的《新版HSK（1–6级）考试结构与样题示例》及[当前官方样卷入口](https://www.chinesetest.cn/HSK)核实，详细来源见 `web/data/hsk3/exams.json`。1–6 级笔试题数为 40 / 60 / 70 / 70 / 72 / 82；3–6 级口语另列。当前 7–9 级为 91 题、约 200 分钟，覆盖五项技能，不能混用旧版 98 题/210 分钟结构。练习都是原创缩短示例，不是完整官方试卷；作文、口语、翻译只做参考和自评，练习正确率不换算官方成绩。实际报考安排以考试中心为准。

新数据按约 200 KiB 的完整词条分片，每片都有哈希、字节数、序号范围。单词详情仅取目标分片；进入某级加载该级，累计词表和全局查词会加载所需其他级。新应用离线缓存含第一级，其他分片在访问后缓存。旧 HSK 2.0 六份源词表、`hanyutong-v2` 数据键和 `HYT2:` 备份格式继续保留。`legacy-bridge.json` 将旧词按词头和读音映射到统一课程：4,672 条唯一匹配、24 条多义映射、106 条不同读音、189 条未收录词。后两类作为明确标注的补充词保留，避免误删不同读音。统一课程各阶段新增为 309 / 207 / 524 / 1,027 / 1,652 / 1,976 / 5,600；这包含教学补充词，不改变官方分级数字。

旧进度迁移前保留备份，已有统一记录优先；多义映射只迁移首个官方义项，不替用户完成其他义项。收藏、复习和统计按统一 ID 去重，旧语法、对话、阅读和练习都留在课程中。离线可用时读取已保存的词条快照；桥接暂时无法加载不会清空原进度。桥接由 `python3 scripts/build_hsk_bridge.py` 确定性生成。

重建词表需先构建大БКРС，下载已锁定哈希的官方 PDF，安装 `pypdf`，再执行：

```sh
python3 scripts/build_hsk3_vocab.py --pdf /path/to/official-hsk-syllabus.pdf
python3 -m unittest discover -s tests -p 'test_*.py'
node --test tests/*.test.cjs
```

构建校验 1–11,000 序号、官方分级、俄语覆盖和每片哈希；同一输入二次构建输出逐字节一致。发布直接使用已核验的词表分片，不在每次发布时重新抓取变动中的大纲。

## 扩展词库的构建与验证

GitHub Pages 发布流程从官方地址下载固定日期的源数据，核验 `dictionary-sources.json` 中的 SHA-256，再构建词库。所有约 97 MiB 的压缩分片随 Pages 一起发布；浏览器只向本应用请求所需分片，不调用第三方在线词典。词典缺少拼音时不凭单字猜测多音词读音。中文查询按完整写法和前缀检索，俄语查询按 3 字母以上的关键词及其前缀检索，多个关键词取交集，返回前 60 项。

```sh
python3 scripts/fetch_dictionary.py
python3 scripts/build_dictionary.py --bkrs .dictionary-cache/dabkrs_261105.gz --unihan .dictionary-cache/Unihan-17.0.0.zip --scratch .dictionary-cache/build.sqlite
python3 -m unittest discover -s tests -p 'test_*.py'
node --test tests/*.test.cjs
python3 -m http.server 8765 --directory web
```

重建时给 `--scratch` 指定一个不存在的新文件路径。源数据下载失败或校验不符时发布会停止，避免悄悄换入不同版本。大БКРС 原始 3,464,739 条中，筛除无汉字标题或无俄语释义的 1,664,523 条，合并 1 条重复标题，得到 1,800,215 条。所有压缩分片的哈希、大小和统计写入生成的 `manifest.json`。生成目录被 `.gitignore` 排除，构建工具、来源、版本和验证全部在仓库中。

大БКРС [下载说明](https://bkrs.info/p47)允许词库自由用于任何目的，完整出处与转换说明见 `web/data/DICTIONARY-SOURCES.txt`。Unihan 采用 Unicode License v3，许可文件随应用提供；只导入字符元数据，不导入英语释义。fflate 0.8.2 的 MIT 许可见 `web/vendor/fflate-LICENSE.txt`。

## 云端教材库

「Учёба → Путь к успеху」提供《成功之路》21 个分级目录，包含593个材料：29份PDF、544段MP3、20份课件。目录和操作界面使用俄语，教材保留原文；教学参考文档不在学习目录中。

教材和课件均在App内分页阅读。音频播放器位于对应教材或课次旁边（窄屏下方），支持变速、循环、进度恢复和连续播放。课次与录音编号按已核对的对应关系展示，不按文件顺序猜测。

阅读界面没有下载、外部打开或离线保存入口。设备仅保存阅读和播放进度，教材需要联网查看。PDF阅读器为PDF.js 6.5.438，遵循Apache-2.0许可。

当前App没有云端用户账号。页面内阅读不能保证阻止截图、录音或从已经显示的内容中提取数据。


## 文字与拍照翻译

主页、学习页和词典页可进入翻译。文字翻译调用 Yandex Translate；拍照使用 Yandex AI Studio 托管的 `qwen3.6-35b-a3b` 视觉模型识别中文、俄文等图片文字。照片经用户点击识别后发送给 Yandex；应用不持久保存图片或翻译内容。识别后的文字可先校正，翻译每次最多 2,000 个 Unicode 字符。相册图片先缩至最长边 1,800 像素，重新编码为 JPEG，去除原文件元数据并限制为 1.5 MiB；无法解码的图片会提示换图。手写、模糊和复杂排版的识别结果可能需要修改。模型输出达到长度上限时会提示识别内容被截短。

服务凭据只在云端使用。文字翻译默认全应用月上限为 100,000 个字符；图片识别与对话、语音共同使用下方 AI 预留额度。两类额度都在调用前持久预留，并发请求不会越过对应的应用限额，存储不可用时停止调用。失败或超时不自动退还预留额度，以免重复调用越过限额。到达限额会提示稍后再试，不自动加购。学习账号注册和云端进度同步仍未接入。

后端验证包含输入尺寸、图片格式、跨域请求、并发额度、月份切换和外部服务错误；相机入口调用设备自己的拍摄界面，桌面浏览器也可选图。图片识别与翻译需要联网。

## AI 对话、视觉与语音配置

入口为 `#/ai`（对话）和 `#/ai/explain`（讲解），主页、学习页和熊猫弹窗均可进入。DeepSeek 默认使用 `deepseek-flash`，服务端也接受 `deepseek-v4-flash` 标识。模型按用户选择的 HSK 1–9 调整难度，返回独立的中文、拼音、俄语译文、俄语解释、纠错及最多两个新词。每次输入最多 2,000 个 Unicode 字符；携带最近完整问答，最多 11 条消息、合计 8,000 字符。较早的完整问答会退出上下文；过长的旧回答只保留标注省略的上下文摘录，屏幕上的完整回答和当前用户输入不被截短。模型输出上限为 1,200 token；不完整或格式错误的结构化答案按失败处理，不自动重试或假装完成。

当前会话离开页面即清除，不写入聊天历史。无历史的首次「讲解」有**仅驻留内存的短期缓存**：有效请求的模式、等级、完整消息与学习画像必须一致，最多 20 项、15 分钟；读取返回独立副本。多轮对话、练习评分、失败或截短答案不使用这个缓存，过期和超限条目会移除，取消的请求不会写入缓存。它不是离线聊天记录，也不会同步到其他设备。

发送对话时，应用可附带本机学习画像中的最多 40 个已学词、10 条语法/用词提示和 10 条声调练习提示。画像仅保存固定类别与次数，不复制纠错原句、录音、用户姓名或聊天内容；疑似联系方式不会进入画像请求。AI 新词必须点击「В мой словарик」才加入，重复词及不同读音由单词身份规则处理。声调提示只是既往本地练习的近似结果，不作为当前发音正确与否的证据。

接口均由同一 Yandex API Gateway 转发至 Cloud Functions，前端不包含提供商密钥：

| 接口 | 输入与返回 |
| --- | --- |
| `GET /ai/config` | 返回 `enabled`、`visionEnabled`、`ttsEnabled`、`asrEnabled`、`assessmentEnabled`、`feedbackEnabled`、`maxInputChars`；未配置的能力保持关闭 |
| `POST /ai/chat` | `{messages:[{role,content}],mode:"dialogue"或"explain",level:1…9,profile?}` → `{text,reply:{zh,pinyin,ru,explanationRu,corrections,newWords}}` |
| `POST /translate/photo` | `{image:base64,mimeType,language}` → `{text,truncated?}`；图片由 Yandex AI Studio 处理 |
| `POST /ai/speech` | `{text}` → `{audio:base64,mimeType:"audio/wav"}`；最多 300 个字符，中文语音模型 `qwen3-tts-flash` |
| `POST /ai/transcribe` | `{audio:base64,mimeType:"audio/wav"}` → `{text}`；中文识别模型 `qwen3-asr-flash` |
| `GET /ai/tasks` | 返回原创任务的 ID、模式、等级、题目和固定评分规则，不提前返回参考答案 |
| `POST /ai/assess` | `{mode:"writing"或"speaking"或"grammar",taskId,answer}` → 教学分数、分项解释、修改稿、参考例文和评估范围说明 |
| `POST /ai/feedback` | `{prompt,answer,reason,consent:true}` → `{saved:true}`；只接受明确同意的有限问题/答案摘录 |

语音录制先留在本机，最多 30 秒、原始录音最多 3 MiB，再转换成单声道 16 kHz PCM16 WAV（44 字节规范文件头、最多 960,044 字节）。点击「Распознать запись」才把录音发送至 Alibaba Cloud；转写结果进入可编辑输入框，仍需点击发送才会交给 DeepSeek。中文朗读也必须主动点击，语音不会自动播放。聊天消息及当前上下文由 DeepSeek 处理，照片由 Yandex 处理，AI 语音和朗读文本由 Alibaba Cloud 处理。普通调用不持久保存原始内容，只保留限额计数和散列化来源；用户明确提交的纠错反馈是单独说明的例外。

拍照识别后的文字可转入 AI 讲解作为一次性内存草稿。用户仍需检查内容并点击发送；图片不会随文字自动转发到 DeepSeek，长文本也不会被静默缩短后收费。

### 原创作业练习与声调范围

`#/assess/writing`、`#/assess/speaking` 和 `#/assess/grammar` 使用 **27 个原创任务（9 个目标难度 × 3 种模式）**。它们是教学练习，不是官方真题库、完整 HSK 模考或对官方 7–9 级共用考试的重新划分。题目、级别、评分标准和参考例文由服务器固定；客户端只能提交任务 ID 和最多 2,000 字的答案，不能改题或指定分数。服务端使用 `deepseek-v4-pro`，最多 2,000 输出 token，思考内容不返回前端；总分必须与固定分项一致，格式或规则不符则不展示分数。

口述模式只检查用户确认后的**文字内容**，不根据 ASR 文字评音素、声母韵母、流利度或声调；分数不换算为正式考试成绩。当前不设置会员、订阅或付款门槛，也不要求伪造账号权限，仅按服务配置与统一预算决定是否调用。

`#/pronunciation` 是另一套设备端的单音节练习：最多录制 5 秒，通过实际 PCM 音频提取基频，展示相对半音变化与示意线。它只能给出一个「ma」的近似声调形状反馈，不能识别实际说了哪个汉字或判断整句发音正确性。轻声、连读变调、噪声、短音、重复音节和证据不足的情况不硬评分；第三声示意是孤立音节的完整轮廓，不能直接套用于自然语流。本功能没有经过标准化语音测评验证，不产生官方分数，也不上传录音。

### 用户纠错反馈

回答下方的反馈入口先展示要发送的问题与答案，再选择「内容有误／解释不清／难度不合适／其他」。勾选独立同意框并点击发送后，才会写入私有对象路径 `app-private/ai-feedback/`；不会自动记录整段对话，也不调用收费模型来代替人工核查。单次问题最多 2,000 字、答案摘录最多 12,000 字，请求最多 48 KiB；当前全应用每月最多 20 条、单来源每日 3 条、单月对象最多 350 KiB。反馈仅作为待核查材料，提交并不表示模型答案已被自动修正。保留和删除由云端维护者管理，当前不宣称已配置自动到期删除。

反馈与两类用量计数共用的私有存储桶容量上限为 **128 MiB（134,217,728 字节）**；部署会同时处理新建桶和已有桶，已有桶仅更新容量字段并核验结果，保留访问权限与已有数据，不添加自动删除规则。该上限为按月保留记录预留空间，并非预购容量；存储费按实际占用空间计算，操作和出站流量另计，详见 [Yandex Object Storage 计费规则](https://yandex.cloud/en/docs/storage/pricing)。

## 内容生产、人工复核与 50 问回归

`data/ai-evaluation.json` 是 **50 个原创中文/俄语回归问题**，包含 1–9 级目标难度、词汇、语法、情景、纠错、歧义、指令注入和偏题请求。每题有人工判断的质量要求及有限的格式检查。它不是 50 次线上模型调用已全部通过的报告，也不是官方 HSK 题目。离线验证只检查数量、覆盖面和结构；有俄语、拼音或正确 JSON 并不代表语言知识一定正确。

```sh
node tools/ai-content.mjs evaluate --offline
node tools/ai-content.mjs evaluate --run --limit 1 --output work/evaluation.json
```

实际调用必须显式加 `--run` 和 `--limit 1…5`，可用 `--offset` 分批选择。工具仅调用现有预算保护的 `/ai/chat` 或 `/ai/speech`，不读取提供商密钥，不绕过全应用额度。报告区分实际尝试数、复用数和机器格式检查结果，并始终保留人工语义复核要求，不能把少量调用标为 50 问全通过。当前来源限速为每分钟 4 次，选择 5 次可能遇到额度拒绝；工具不自动重试。

先制作生成计划，再批量生成一次性草稿：

```sh
node tools/ai-content.mjs template --output work/content-plan.json
node tools/ai-content.mjs generate --run --limit 3 --input work/content-plan.json --output work/drafts.json
node tools/ai-content.mjs validate --input work/drafts.json
```

模板仅包含三个待生成请求，分别示范 HSK 例句、情景对话和俄语解释，不把它们标成人工复核完成的教材。生成的条目默认为 `review.reviewed:false`。人必须实际检查中文、拼音、俄语、难度与情景；逐条填写 `review.reviewed:true`、`review.reviewedBy`、`review.decision:"approve"` 或 `"reject"`，并将该条目的 `contentHash` 复制到 `review.contentHash`。工具检查声明和哈希一致性，不声称能够验证复核者身份。

如人工修改了内容，先生成新的复核队列；该命令会重新计算哈希并将所有旧复核声明重置为未复核，之后再由人确认：

```sh
node tools/ai-content.mjs prepare-review --input work/edited-drafts.json --output work/review-queue.json
node tools/ai-content.mjs approve --input work/reviewed.json --output work/approved.json
```

只有明确复核并批准的条目进入输出，未复核、被拒绝或生成未完成的条目不会混入；没有批准内容时拒绝创建空的「已批准」文件。需要进入静态资源时可显式执行 `build --input work/reviewed.json --output web/data/ai-content.json`，但工具不会提交 Git、发布网站或把文件自动显示在课程中。当前仓库不预置虚假的已复核内容或空占位教材。

固定课文语音只接受已批准的内容文件；不带 `--run` 时只预览计划：

```sh
node tools/ai-content.mjs tts --input work/approved.json --limit 3 --output-dir work/course-audio
node tools/ai-content.mjs tts --input work/approved.json --limit 3 --output-dir work/course-audio --run
```

文字按最多 300 字分段，以固定语音配置和文本的哈希去重；相同文本只生成一次，复用前校验音频文件哈希。每个收费尝试先写入工作日志，即使进程中断或响应失败，后续运行也不会自动再次收费。丢失、损坏、失败或不确定的缓存需要人工检查后再决定是否重做。生成、评测报告和音频缓存只能写入仓库 `work/`；可发布的内容导出必须是单独明确执行的复核后构建。预生成语音的成功与否取决于普通 Qwen 语音服务是否已经配置，工具的存在不表示课程音频已经全部生成。
